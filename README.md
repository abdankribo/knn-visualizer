# KNN Visualizer

Interactive machine-learning laboratory untuk memahami K-Nearest Neighbors.

## Fitur
- Interactive coordinate plane
- K value selector
- Euclidean distance
- Distance ranking
- Majority voting
- Manual point insertion
- Visual connection ke tetangga terdekat
- Dataset demo
- Responsive UI

## Teknologi
HTML, CSS, JavaScript Canvas.

## Konsep
`distance = √((x1-x2)² + (y1-y2)²)`
